# مراجعة كل لقطة

- [ ] الفكرة مفهومة بصريًا، وليست مجرد عنوان فوق كروت عامة.
- [ ] لا إحصاءات أو حقائق أو واجهات منسوبة لمنتج بلا تحقق.
- [ ] الألوان والخط متسقة مع STYLE.md.
- [ ] العربي متصل واتجاهه سليم؛ النص قصير ولا يتجاوز حدوده.
- [ ] الدخول والحركة والوقفة تخدم المعنى؛ القراءة مريحة بالحجم الفعلي.
- [ ] الكروت والخطوط والأيقونات لا تتداخل بصورة غير مقصودة.
- [ ] وقت الصوت متوافق مع وقت الفعل؛ لا clipping.
- [ ] مستوى المؤثرات جُرّب مع صوت مصطفى، أو ذُكر أن ملف صوته غير متاح.
- [ ] تم فحص البداية والذروة والنهاية، ونوع الاختبار موثّق.
- [ ] المصدر قابل للتعديل، وملف التصدير يعمل بالدقة والمدة المتفقتين.
- [ ] التقرير يفرق بين ما نُفّذ وما هو مقترح أو غير مُختبر.
