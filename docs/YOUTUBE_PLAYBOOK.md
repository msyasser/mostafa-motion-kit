# YouTube editing — Mostafa Yasser

دليل للمحرر أو الـAI. اقرأ معه STYLE.md وDHAYY.md وEDITING_WORKFLOW.md.

## الثوابت

- الصوت الأساسي صوت مصطفى؛ لا يستبدل بتعليق مولّد.
- الهوية بني وذهبي، والعربي داخل الفيديو Tajawal.
- ضيّ هو الشخصية الرئيسية عندما تحتاج الفكرة لوجود شخص.
- مؤثرات خفيفة تدعم الحركة؛ بلا موسيقى افتراضيًا.
- تسجيل الشاشة الحقيقي يحتفظ بألوانه. الواجهات الرمزية لا تقدّم كدليل على ميزة حقيقية.
- B-roll افتراضي 16:9، 1920×1080، 30fps. الفيديو الكامل يتبع المادة الأصلية وطلب التسليم.

## تجهيز مشروع

اجمع السكريبت أو التسجيل والمواد الأصلية والهدف وأي متطلبات للمدة/المقاس/برنامج المونتاج. لا تسأل عن معلومات سبق ذكرها. افحص الملفات قبل تحديد التوقيت؛ لا تخمّن كلامًا لم تسمعه.

اكتب خريطة مونتاج: البداية والنهاية، جملة مصطفى، الصورة الأساسية، سبب الـB-roll، الحركة، الصوت، اسم الملف. استخدم examples/youtube-edit-plan.csv؛ صفّه الأول مثال وليس توقيتًا حقيقيًا.

## التنفيذ

1. رتّب السرد أولًا، واحذف التكرار غير المقصود بدون تغيير المعنى.
2. ضع B-roll عندما يشرح أو يوضّح أو يقدم مثالًا. لا تغطِّ كل الجمل بكروت.
3. نفّذ من القوالب أو ابنِ مشهدًا يناسب الفكرة وفق REFERENCE_STYLE.md.
4. اترك مساحة للمتحدث وتسجيل الشاشة والهدوء البصري؛ لا تفرض قطعًا دوريًا بلا سبب.
5. امزج المؤثرات مع صوت مصطفى وراجع السمع الفعلي والذروة والقطع.
6. راجع الفيديو كاملًا ثم صدّر نسخة مراجعة ونسخة نهائية عند طلبها.

## التسليم

فيديو يعمل بالدقة والمدة المتفقتين، MP4 مستقل لكل B-roll، مصادر قابلة للتعديل، خريطة المواضع، وتقرير موجز بالاختبارات والقيود. مشروع Premiere/Resolve لا يُسلّم إلا إذا أُنشئ بصيغته الصحيحة وتم فتحه واختباره.

## حدود النسخة

الريبو يوفر Remotion، ثلاث دراسات سينمائية جديدة، ثلاث قوالب بسيطة قديمة، مؤثرات، أصل ضيّ وإرشادات. لا يتضمن محرر فيديو كاملًا، تفريغًا أو إزالة صمت أو مزامنة كلام تلقائية مدمجة، مشروع Premiere/Resolve، أو اتصال HeyGen. يضيف المحرر/الوكيل القدرات المطلوبة بأدواته ويتحقق منها. قراءة الرابط وحدها لا تمنح الـAI قدرات تشغيل أو رندر.
